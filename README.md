# Mojdeh Saadati personal website

This is a static GitHub Pages site designed to keep the clean, research-first structure of the reference website while making the content easier for both people and AI agents to parse.

## Files
- `index.html` — main site
- `styles.css` — styling
- `llms.txt` — concise AI-agent-readable profile
- `profile.json` — machine-readable researcher metadata
- `publications.json` — machine-readable publication list
- `robots.txt` and `sitemap.xml` — crawler support

## Before publishing
1. Replace the `MS` image placeholder with your headshot if desired.
2. Add your current CV as `Mojdeh_Saadati_CV.pdf`.
3. Verify publication titles/statuses and add DOI/arXiv links where available.
4. Copy these files into the root of your `mojdeh-saadati.github.io` GitHub repository and commit/push.
